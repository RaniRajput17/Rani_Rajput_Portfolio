# Rani Rajput — Portfolio

Recruiter-focused responsive portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` directly, or run `python -m http.server 5500` and visit `http://localhost:5500`.

## Deploy
Works with GitHub Pages, Netlify, Vercel, Cloudflare Pages or AWS S3 static hosting.

## Before publishing
- Add GitHub URL if you want recruiters to see public code.
- Add only project/demo links that you are allowed to share.
- Keep all project claims aligned with your real experience.
